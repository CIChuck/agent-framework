      Friday remembers,
      so you don’t have to.

      Build AI agents with genuine persistent memory, adaptive learning, and multi-agent collaboration. Provider-agnostic. Protocol-first. Production-ready.

      Get Started → View on GitHub
      pip install friday-agent

      The Memento Problem

      Every AI conversation starts from zero.

      You explain your preferences. You provide context. You repeat background information you shared last week. The AI responds intelligently — but it doesn’t remember. It doesn’t learn. It doesn’t grow with you over time.

      This isn’t just inconvenient. It’s a fundamental barrier to AI reaching its potential as a genuine cognitive partner.

      “Imagine waking up every morning with complete amnesia — unable to recall yesterday’s work, last week’s decisions, or the lessons learned from months of experience. That’s the reality of stateless AI assistants.”

      Friday solves this at the architecture level.

      What Friday Gives You

      Persistent Multi-Tier Memory

      Episodic + Semantic + Associative. Hebbian learning ensures what matters rises to the top. Memories decay naturally — and reactivate on demand.

      Provider-Agnostic LLM

      OpenAI, Anthropic, Ollama, OpenRouter. One config line to switch providers. Same agent code works with GPT-4, Claude, Llama 3, or Mistral.

      Protocol-First Design

      16 packages, each defined by abstract protocols. Swap ChromaDB for Pinecone, replace NetworkX with Neo4j, bring your own LLM client. Zero lock-in.

      Multi-Agent Collaboration

      Shared memory plane. Provenance tracking. When one agent learns, all agents benefit. No handoff cost, no context duplication.

      Production Observability

      Full conversation transcripts in SQLite. Structured JSON logging. OpenTelemetry hooks. Every tool call, token count, and latency recorded.

      YAML-First Configuration

      Deterministic, auditable runtime behaviour. HIPAA/GDPR/SOC 2 deployment patterns. Compliance-ready by design.

      import asyncio
from friday_agent import CopilotAgent
from friday_agent.config import AgentConfig

async def main():
    config = AgentConfig.from_yaml("config.yaml")
    agent  = CopilotAgent(config)

    # First session — agent stores context in memory
    response = await agent.chat("My name is Alex. I'm building a RAG pipeline.")
    print(response.content)

    # Later session — agent remembers without being told again
    response = await agent.chat("What was I building?")
    print(response.content)  # "You were building a RAG pipeline."

asyncio.run(main())

      How Memory Works

      Memories move through a lifecycle:

      1
2
3
4

      EPISODIC ──► SHORT_TERM ──► LONG_TERM ──► DECAYED
                                             │
                 ◄───────────────────────────┘
              (reactivated on access — never truly lost)

      Decay formula: score(t) = score₀ × exp(−λ × hours_since_access)

      The λ decay rate is configurable per use case. Memories that are accessed more often build stronger weights through Hebbian reinforcement and resist decay.
