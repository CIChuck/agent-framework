Product Requirements Document (PRD): massive-agent-core 1. Executive SummaryProject Name: massive-agent-corePurpose: A robust, asynchronous Python wrapper for the Massive API specifically engineered for AI agent frameworks. It provides "smart" access to market data, technical indicators, and financial metadata while managing rate limits and data latency based on the user's subscription tier.2. Goals & ObjectivesAgentic Integration: Create a Pythonic interface that returns structured, JSON-ready data for LLM-based agents.Asynchronous Execution: Support long-duration tasks and concurrent data fetching without blocking the main agent loop.Official SDK Utilization: Build directly upon the official massive Python SDK to ensure compatibility with future API updates and rebrand-specific features.Tier Sensitivity: Automatically adjust behavior (rate-limiting, endpoint selection, and data granularity) based on whether the user is on the Free or Starter ($29/mo) tier.Market Resilience: Implement "Market Day" logic to ensure requests for historical or current data account for market closures.Comprehensive Data Scope: Cover US Equities, major Stock Indices (via proxies), Bond Market proxies (ETFs), and Crypto (BTC/ETH).3. Technical Foundation3.1. Primary SDKmassive (official): Used for core REST connectivity and data modeling.3.2. Supporting Librariesaiohttp: To handle asynchronous HTTP requests beyond the SDK's standard capabilities, specifically for custom "Governor" logic.pandas: For structuring market aggregates and performing local data cleaning.asynciolimiter or aiolimiter: To implement the token-bucket rate limiting strategy for the Free Tier.python-dotenv: For secure management of API keys and tier configuration.4. Functional Requirements4.1. Core Transport & ResilienceAsync Client: Built using aiohttp for non-blocking I/O.Governor (Rate Limiter): - Free Tier: Strict 12-second delay between calls (5 req/min).Starter Tier: Near-instant execution (Unlimited).Error Handling: Custom exception hierarchy (MassiveRateLimitError, MassiveAuthError, MassiveMarketClosedError) with automatic exponential backoff.4.2. Market Data ModulesEquities: Fetch daily OHLCV and granular minute-level aggregates.Crypto: Support for X:BTCUSD and X:ETHUSD with 24/7 market logic.Indices & Bonds (The Registry): A built-in mapping system to translate human-readable concepts into accessible tickers (e.g., "S&P 500" -> SPY).Asset Metadata: Enrichment of every query with company names and descriptions using the Reference API.4.3. Technical IndicatorsNative Support: Leverage Massive’s indicator endpoints for SMA (50-day and 200-day).Fallback Logic: Capacity to calculate indicators locally (via pandas) if API limits or data gaps occur.4.4. Date & Filtering LogicSmart Date Resolver: Automatically rolls "To" and "From" dates to the nearest valid Market Day.5. Non-Functional RequirementsPerformance: Asynchronous requests should minimize latency overhead.Extensibility: Modular design to allow adding "Options Analysis" or "WebSockets" in Phase II.Security: API keys must be handled via environment variables (no hardcoding).Documentation: Inline docstrings for every method to ensure agent frameworks can "read" the tool's purpose.6.
