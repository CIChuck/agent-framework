# Documentation Archive

Archive material is retained for history, provenance, and audit. It is not
current implementation authority unless a current planning, reference, or
architecture document explicitly incorporates it.

## Lifecycle Collections

- [completed](completed/) — implemented work grouped by completion year and
  initiative.
- [superseded](superseded/) — plans and specifications replaced or overtaken by
  implementation or newer direction.
- [source-materials](source-materials/) — external or raw inputs retained for
  provenance.
- `research-notes/` — exploratory research.
- `agent-phase-artifacts/` — historical agent framework phase packets.
- `analysis/`, `design-notes/`, `ephemera/`, `recovery/`, and `obsidian/` —
  retained legacy collections awaiting only indexing, not flattening.

## Archive Contract

- Completed packets identify implementation, validation, or release evidence.
- Superseded packets should identify a successor when one is known.
- Open follow-up work must be split into planning before its parent is archived.
- Historical body text is preserved even when its embedded status became stale;
  the packet index explains the final disposition.
- Files do not return to active planning without an explicit maintainer decision.
