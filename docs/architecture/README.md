# Current Architecture

This directory is reserved for architecture that describes the current system or
an explicitly accepted target architecture.

Initiative-specific proposals now live with their planning packets. Completed
phase designs live in `archive/completed/`, and superseded designs live in
`archive/superseded/`. At this checkpoint there are no standalone current
architecture documents left here; current package behavior is described by
package source, tests, durable reference contracts, and active initiative
packets.
