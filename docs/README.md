# Documentation

This folder is organized by document purpose, not by implementation phase.

## Current Folders

- [guides](guides/) - User, operator, and contributor guides.
- [reference](reference/) - Stable technical reference: policies, specs, provider notes, testing references, and audits.
- [architecture](architecture/) - Current architecture notes and active design material.
- [planning](planning/) - Active or proposed work: build plans, backlog, PRDs, feature notes, and roadmap material.
- [archive](archive/) - Historical, superseded, exploratory, or evidence-bundle material retained for searchability.

## Routing Rules

- Put "how to use Friday" material in `guides/`.
- Put contract/reference material in `reference/`.
- Put current system design decisions in `architecture/`.
- Put future work and proposed changes in `planning/`.
- Put completed plans, old phase artifacts, scratch research, and superseded designs in `archive/`.

When a document moves from proposal to durable contract, promote it from
`planning/` to `reference/` or `architecture/` as appropriate.
