started. Friday TUI has planning-only authority, with the command refactor as

each retains its own approval and acceptance gates.

under [`docs/archive/completed/2026/`](../../archive/completed/2026/). The
[archival relocation receipt](../../archive/completed/2026/archival-relocation-2026-10-24.json)
