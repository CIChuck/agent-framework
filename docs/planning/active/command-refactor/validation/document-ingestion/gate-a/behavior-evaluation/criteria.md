# Direct Docling behavior evaluation — bounded implementation criteria

Current authority is the [focus amendment](behavior-focus-amendment.md), implementing
Chuck's latest direction within the existing isolated readiness work. This is a
standalone document-behavior slice, not full A0–A4 or product qualification.

| ID | Required evidence |
| --- | --- |
| BE-01 | Test-only source and planning scope; protected product/config/lock/store bytes and metadata preserved. |
| BE-02 | Standard private wheel profile; actual Docling/RapidOCR origins and post-install Certifi >=2026.10.19. No custom package resolver prerequisite. |
| BE-03 | Explicit private environment and caches, isolated/no-site Python, network denial during conversion; honest Python-visible/native limits. |
| BE-04 | Genuine 30-document PDF/DOCX/XLSX/PPTX matrix plus seven corrupt/size/format controls; distinguish native conversion from structural admission and setup failures. |
| BE-05 | Retain raw default failures, empty/encrypted outcomes, OCR/table/order/hidden-content/notes findings and original independent oracles. No placeholder or alternate extractor supplies document text. |
| BE-06 | Demonstrate public Docling settings for body/furniture, isolated headings and unambiguous notes; comments and unsupported spreadsheet data do not leak into admitted chunks. |
| BE-07 | Default512 and explicit64/128/512/1024 budgets across document/recursive/fixed. Prefix and special tokens counted, source content checked. Test prototypes and unqualified server-counter agreement disclosed. |
| BE-08 | Refused, empty, partial, failed or stale output excluded from admitted chunks. Independent content oracles and final prepared token limits checked. |
| BE-09 | Bounded conversion/setup time, sampled RSS/disk and cumulative active time; terminate only owned process groups and retain logs. |
| BE-10 | All57 retained minimal cases, the original eight behavior cases and named BE-REV-001 regressions pass normal/-O; retained parser/engine selectors, focused Ruff/format and private mypy pass without product changes. |
| BE-11 | Reproducible manual evaluate/report commands, local inputs/outputs and meaningful error/phase reporting. No model service or store effect. |
| BE-12 | Frozen source candidate and hash-bound evidence; independent review separates executed from inspected proof. Full-framework compatibility, model-window, embedding/storage and human acceptance remain open. |

The reader/asset stack is the ordinary selected private profile. Tests of future
framework consumers, installed full-Friday profiles, live Friday-LLM embeddings,
Chroma storage, real personal documents and production `/ingest` integration are
excluded. No older score or review qualifies changed behavior code.
