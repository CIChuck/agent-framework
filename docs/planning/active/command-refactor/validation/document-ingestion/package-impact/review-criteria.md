## Honest scores and outcomes

Return exactly VERIFIED, CHANGES_REQUESTED or BLOCKED, with every PI-01–18
criterion assessed from evidence. Each mandatory finding identifies severity,
affected text, controlling requirement, source/authority evidence, risk, bounded
document correction and recheck. Keep optional advisories separate. A reviewer
does not repair, delegate, stage or mutate the checkout.

Score each rubric independently out of 10; use the actual totals, not a target.

| Coverage rubric | Maximum |
| --- | --- |
| All-package inventory and accurate source/dependency/test classification | 3.0 |
| Material behavior, configuration and data effects | 2.0 |
| Shared ownership and dependency/deployment consequences | 2.0 |
| Traceable boundaries, compatibility and required proofs | 2.0 |
| Unresolved readiness details and approval completeness | 1.0 |

| Overall rubric | Maximum |
| --- | --- |
| Accuracy against current scope and source | 3.0 |
| Architecture and bounded delivery | 2.0 |
| Data/configuration/dependency safety | 2.0 |
| Evidence, future-work distinctions and reproducibility | 1.5 |
| Maintainer readability and approval/change control | 1.5 |

Every seat must be VERIFIED, have no mandatory findings and independently score
at least 9.5 on both rubrics to end the loop successfully. Mandatory findings
override high scores; no seat average, score coaching or threshold inflation.
Review remains valuable below the threshold. The controller may make bounded
document corrections within the original four-round cap, exhausted after
round4. Chuck explicitly authorizes one additional full round5, recorded in
[the extension](round5-authorization.json); no reset, replacement or round6.
If that gate is unmet, stop for further guidance. A material change
to the frozen technical scope stops for explicit disposition.
