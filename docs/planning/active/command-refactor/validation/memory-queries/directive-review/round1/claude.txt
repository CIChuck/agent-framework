SESSION's own `neutral_behavior` asserts 24 names, so appending sixteen gives 40, not 54. Only DIAG's `retained_session_neutral_behavior` (38 names) satisfies the plan.   Suggest `TypeError` for type errors, `ValueError` for invariants, checked in declaration order.

  - a non-`str` `description` in metadata (warn, None, or coerce?);
  - promotion is add-then-delete (`collection_manager.promote_memory`), so a transient or crash-left duplicate id is counted twice. Consider deduplicating by record id, or documenting it;
  - say explicitly whether `No ingested documents.` can be followed by a `Warnings:` block.
- **A8.** The mutation list lacks the distinctions the edited version introduced:
  - plain-record metadata reads;
  - a `complete` read outside the empty-meta branch;
  - verification evaluated after text;
  - a query-failure `try` that wraps projection;

  - None-first description sort.
- **A9.** The `memory.py` allowlist does not mention imports. Wrappers calling `memory_queries` while `memory_queries` imports `preview_text` from `memory` is a circular import. Say whether wrappers import lazily, and whether now-unused `memory_views` imports may be removed (registry has that permission; `memory.py` does not).
- **A10.** The materialization heredoc runs `"$MEMQ_PYTHON" -B -` from the repository root without `-I`. Prefer `-I -B`.
- **A11.** Board `next` selects `friday-langfuse-integration` (AWAITING_APPROVAL), not this initiative. `show friday-command-refactor` confirms `started` / `granted` / `feature/command-retirement`. Note this in next-phase so the AGENTS steps are unambiguous.
