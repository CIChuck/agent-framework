- An exploratory mutant changed the grouping key to `(source, description or None)`. That merges a stored `""` description with an absent (`None`) one, and all 52 tests still pass.

- Real `/ingest` never produces `""` (`registry.py:679` sets `" ".join(...) or None`), so the practical risk is low.
- Mitigation: at D3, add one T14 row with a `""` and an absent description for the same source. This is a test-only change.

**N2 (low, documentation): one descriptive field in `authority.json` is stale.**

- Its sibling `state` already says `D2_implemented_council_pending`.
- The controlling fields named by the directive all agree across the board, packet, log and authority: execution_phase, validation_state, next gate, roster and acceptance pending.
- Mitigation: update the wording at the next controller status write.

**N3 (medium, process/UAT): the pre-existing `/ingest` failure without a description is real and user-reachable, but it is tracked only in packet status prose.**
- My paired controls reproduce it identically on clean pre-D2 and candidate exports, through both the adapter and the real `/ingest FILE` command. Details are in §MD2-11.
- The CMD-F05 backlog row and the framework upgrade log do not record it.
- UAT step MQ-UAT-10 tells the operator to "`/ingest` ... using existing syntax". If an operator omits the description, they will hit the TypeError and may misread it as a MEMQ regression.
- This is not a D2 defect: the directive freezes `/ingest`, and option R's scoped requirements are met.
- Mitigation:
  - Record the defect in the backlog (CMD-F05/FILE-001) for a maintainer decision.
  - Before UAT, have the D3/acceptance handoff tell operators to supply a description.
  - Do not fix or waive the defect in MEMQ.

**N4 (low, traceability): three mandatory behaviours are asserted only in the frozen-case node.**
- The behaviours are `No entities found.` (MQ-T11), absence of a last-turn budget (MQ-T09) and the complete empty-meta message (MQ-T10).
- Each one is asserted by MQ-T07's exact frozen rows (`entities:empty`/`nodes-empty`, `memory:no-turn-no-session`, `meta:empty-complete`), not inside its own node.
- The assertions are effective: mutants hitting these paths fail T07. They are just located in a different node.
- Mitigation: none is required for D2. Optionally, cross-reference them in the D3 test-traceability record.
